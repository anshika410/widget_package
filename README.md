   # widget_package
   Reusable animated backgrounds and widget animations.

   ## Install
```
   flutter pub add widget_package --git-url=https://github.com/YOUR_NAME/widget_package.git --git-ref=v0.1.0
```

   ## Use
```dart
   import 'package:widget_package/widget_package.dart';

   WaveBackground(child: Center(child: FadeSlideIn(child: Text('Hello'))))
```
